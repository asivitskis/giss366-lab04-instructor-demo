# GISS 366/368 · Lab 4 Starter Repository

This is the starter repository for **Lab 4: JavaScript & Leaflet in Practice**, part of Week 5 in our GISS 366 Web Mapping & Web GIS course at WNMU.

## Before you clone this

Don't clone this repository directly. Instead:

1. Click the green **Use this template** button above, then **Create a new repository**.
2. Set the visibility to **Public** (required for GitHub Pages to work on a free account).
3. Create the repository under your own GitHub account.
4. Clone *that* new repository, following the Lab 4 instructions.


## What's in here

| File | Purpose | Edit today? |
|---|---|---|
| `index.html` | The map page: structure, style, and the link to the map script (built on Dorman's `example-02-11.html` pattern) | Yes, HTML and CSS (similar to your Lab 03) |
| `map.js` | Builds the Leaflet map | Yes - this is the primary exercise |

| `js/leaflet.js` | Leaflet library | No |
